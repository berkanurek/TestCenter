## GitHub “Contributors” sidebar

That list is generated from **commit author email** matching a GitHub account. If you see a bot or wrong name, set your local Git email to an address [verified on your GitHub account](https://github.com/settings/emails) (often your `*@users.noreply.github.com` address), then make new commits:

```bash
git config user.name "berkanurek"
git config user.email "YOUR_VERIFIED_EMAIL_FROM_GITHUB_SETTINGS"
```

Rewriting history to change old commits is possible but should be done carefully (force-push, coordinate with collaborators).
